## Roteiros

### 03 — Achar cliente no território (ter)
Filtro → cidade → ramo (CNAE) → lista ranqueada → mapa → "Adicionar ao funil".
- Território em SC, um segmento diferente de confecção.
- Limpeza: remover o vínculo do funil via API.

### 04 — Funil (qua)
Funil de vendas → "Indicadores" (Negócios, Valor em funil) → deslizar entre as etapas → botão → do card → "Negociação".
- **Arrastar card não funciona no celular** (só HTML5 drag). Usar o botão →.
- Nunca mover para "Fidelização": isso converte a empresa em cliente.
- Limpeza: devolver o card à etapa original.

### 05 — Visita com check-in (qui)
Agenda → "Adicionar" → "Visita" → empresa do funil → "Salvar" → "Registrar visita" → "Check-in" → resultado e próximo passo → "Salvar visita".
- Liberar geolocalização no navegador da gravação, com coordenada de Campinas, para o pop-up de permissão não aparecer.
- Limpeza: excluir a atividade.

### 06 — Pedido e comissão (sex)
"Novo pedido" → cliente → representada → item do mostruário → aparece "Comissão prevista" → "Salvar pedido" → "Enviar" → "Faturar" → Comissões ("A receber").
- Faturar gera o lançamento de comissão no mês.
- Limpeza: "Cancelar" o pedido, que cancela a comissão junto.

### 07 — WhatsApp no sistema (sáb)
Buscar conversa → abrir chat → responder → nota interna ("só a equipe vê") → agendar mensagem.
- Na org demo o WhatsApp é circuito fechado: nada sai de verdade.
- Limpeza: apagar a mensagem, a nota e o agendamento criados.
